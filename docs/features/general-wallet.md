# 一般錢包

一般錢包是一份資產：餘額、帳目列表、收支、轉帳、代墊與還款、分類。

## 餘額

- 建立時可以填**初始餘額**（預設 0）。
- 餘額**可以是負的**（例如用來記信用卡）。
- 餘額是**存起來的值**，每次記帳、修改、刪除時當下就更新，
  不是顯示時才從明細加總。
- 可以**調整餘額**：輸入實際餘額，系統把差額（實際餘額 − 目前餘額）記成一筆「調整」交易。
  差額是 0 時擋下（餘額沒有變化），不留一筆 0 的帳。
- 調整**可以刪除、不能修改**：刪除就是反向套用那筆差額。之後修改或刪除更早的帳，
  不會回頭重算調整的差額。調錯了就刪掉重新調整。

**為什麼調整不能改**：調整的意思是「在那個當下，實際餘額是多少」。事後修改要重新問一次
「以哪個時間點的餘額為準」，答案會隨其他帳的修改而變；存成固定差額，刪掉重調就清楚。

| 操作 | 餘額 | 代墊未還金額 |
|---|---|---|
| 收入 | ＋金額 | |
| 支出 | −金額 | |
| 轉帳 | 轉出方 −、轉入方 ＋ | |
| 代墊 | −金額 | ＋金額 |
| 還款 | ＋金額 | −金額 |
| 調整餘額 | 設為輸入的值 | |
| 修改某一筆 | 套用新舊差額 | 套用新舊差額 |
| 刪除某一筆 | 反向套用 | 反向套用 |

## 帳目列表

- **錢包頁就是帳目**：最上方是餘額，下面是帳目列表；其他功能的入口見[錢包頁的版面](ui.md#錢包頁的版面)。
- 列表依**日期新到舊**，同一天的依記帳時間新到舊；一次載入一部分，往下「載入更多」。
- 「記一筆」（收入、支出、轉帳或代墊）與「調整餘額」放在頁面標題列；手機的位置見[錢包頁的版面](ui.md#錢包頁的版面)。
- 列表**依日期分組**，每組的標題是日期，今天、昨天寫成「今天」「昨天」。
- 每一筆的標題優先用**備註**；沒有備註時是分類（轉帳、代墊等沒有分類的，用原本的標題，例如「轉出至 存款」）。
  標題旁邊用膠囊外框標出**分類**，沒有分類的標出類型（轉帳、代墊、還款、調整餘額），跟標題一樣時不重複標。
  備註佔走標題時，轉帳的對方錢包、代墊的對象改寫在下一行，跟記帳人放在一起。
- 金額的正負一眼要分得出來：增加的帶「+」並用綠色，減少的用紅色。
- 點某一筆帳打開詳情：看欄位、記帳人與這一筆的異動紀錄，有權限時可以修改、刪除。

## 收入與支出

- 欄位：金額、分類、日期、備註。日期只有日期、不含時間，預設今天，可以填過去或未來；
  備註選填，最多 200 字。
- 修改時可以在收入與支出之間切換，分類要跟著換成對應類型的。
- 分類被封存之後，修改用過它的帳時**可以保留原本的分類**，但不能改選其他已封存的分類。
- **不做分攤**：一般錢包是一份資產，錢從錢包出去就是錢包的支出。

**為什麼不分攤**：一般錢包代表的是一筆實際存在的錢，錢從錢包付出去就是錢包的支出，
沒有「誰該負擔多少」的問題。需要算誰欠誰的情境用旅遊錢包；錢包替某個人付的錢用代墊記錄。

## 轉帳

- 從一個一般錢包轉到另一個一般錢包，兩邊各產生一筆（轉出、轉入），**一起建立、一起修改、一起刪除**。
- 在「記一筆」裡選類型「轉出」或「轉入」，再選對方錢包；選單列出自己加入的其他一般錢包，不列設為不顯示的。
  欄位：金額、對方錢包、日期、備註，**不選分類**。
- 建立的人必須**同時是兩個錢包的成員**（超級管理者也一樣，沒加入的錢包不能轉）。
- 任兩個一般錢包之間都可以轉，金額原樣搬過去，**不換匯**（見[金額](amounts.md)）。
- 轉帳不算收入或支出。
- 帳目顯示「轉出至 X」「轉入自 Y」，對方錢包的名稱兩邊的成員都看得到。
- 修改**只能改金額、日期、備註**，不能換對方錢包，也不能在轉帳與收支、轉出與轉入之間切換；
  轉錯錢包就刪掉重記。
- 修改、刪除要**在兩個錢包都有權限**：自己記的，要兩邊都還是成員（或超級管理者）；
  別人記的，要兩邊都是管理者（或超級管理者）。記帳人離開其中一個錢包後就不能改刪，再加入後可以。
- 兩邊各自留異動紀錄，紀錄裡存的是當時的對方錢包名稱。
- 其中一個錢包被刪除時，另一邊那一筆**保留、餘額不變**，顯示「已刪除的錢包」；
  之後**只能刪除、不能修改**，刪除時照這個錢包自己的權限，只反向套用這一邊。

**為什麼兩邊都要有權限**：一筆轉帳會改兩個錢包的餘額，只在其中一邊有權限就能改，
另一邊的成員會發現自己的帳被一個沒加入他們錢包的人改了。

**為什麼不能換錢包**：換錢包等於從一個錢包撤掉、在另一個錢包新增，權限與異動紀錄都要跨三個錢包判斷；
刪掉重記一樣清楚，兩邊的紀錄也各自完整。

**為什麼錢包刪除時另一邊保留**：別人刪掉自己的錢包，不該讓這個錢包的餘額跟著變。

## 代墊與還款

代墊的意思是**錢包幫某人墊付了多少**，不是「錢包欠誰」。

- **代墊**：在「記一筆」選類型「代墊」，輸入替誰代墊、金額，備註寫代墊了什麼。**餘額立刻扣掉**。
- **還款是對某一筆代墊**：打開那筆代墊的詳情按「還款」，只輸入金額、日期、備註，
  **餘額加回同樣金額**。同一筆代墊可以分多次還。
- 每筆代墊有自己的**未還金額**（代墊金額 − 已還），每個對象的未還金額是他各筆代墊未還的總和。
  兩者都是**存起來的值**，與餘額一起更新。
- **未還金額永遠不能是負的**，新增、修改、刪除都照這條檢查：
  - 還款不可超過那筆代墊目前的未還金額；修改還款時上限是「未還 + 這筆原本的金額」。
  - 代墊改小金額時，不能小於已還的金額。
  - **已經有還款的代墊不能刪除**，要先刪掉它的還款。
- 代墊與還款都**不能改對象**，只能改金額、日期、備註；還款也不能換到另一筆代墊。對象打錯就刪掉重記。
- 代墊對象**不需要是成員**，自由輸入名字。系統依名字（去掉前後空白，大小寫視為不同）歸成同一個對象，
  輸入時提示這個錢包用過的名字。
- 還款是帳目列表裡**獨立的一筆**（「小明 還款」），有自己的記帳人與異動紀錄，
  改刪權限照一般的帳：自己記的，或管理者。代墊的詳情列出它的每一筆還款。
- 任何成員都可以替任何一筆代墊記還款，不限代墊的記帳人。
- 代墊與還款**不算收支統計，也不選分類**。

錢包頁面顯示目前代墊未還的清單，例如「小明 500、小華 1,200」，只列未還大於 0 的人；
清單只是顯示，還款一律從代墊的詳情操作。

**為什麼還款對某一筆代墊**：代墊的備註記的是墊了什麼，還款對著那一筆，就看得出哪一件還清了、
哪一件還沒；對人的總額再從各筆加總得到。

**為什麼不能改對象**：改對象等於把未還金額從一個人搬到另一個人，兩邊都要重新檢查不能變負，
而還款也得跟著搬。刪掉重記一樣清楚，異動紀錄也各自完整。

**為什麼有還款的代墊不能刪**：刪掉代墊卻留著還款，還款就沒有對象；連同還款一起刪，
又會一次改掉別人記的帳。先刪還款再刪代墊，每一步都照各自的權限與紀錄。

## 分類

- 每個分類都帶**類型**（收入或支出），建立後不能改；記收入只能選收入分類，記支出只能選支出分類。
- 每個一般錢包有自己的分類，建立時附一組預設分類，名稱依建立者的語系寫入，之後就是一般文字：

  | 類型 | 預設分類 |
  |---|---|
  | 收入 | 薪資、獎金、投資、其他 |
  | 支出 | 餐飲、交通、購物、居家、娛樂、醫療、其他 |

- 管理者可以新增、改名、刪除分類。同一個錢包裡，同類型的分類名稱不能重複（去掉前後空白後比對，大小寫視為不同）。
- **刪除分類是封存**：封存的分類不再出現在分類管理與記帳的選單裡，用過它的帳照樣顯示原本的名稱。
  名稱不能重複只看還沒封存的分類，所以封存之後可以再建一個同名的分類。

**為什麼刪除是封存**：分類被帳目引用著，真的刪掉，舊帳就會失去分類或得跟著改。
封存讓管理者照樣能整理選單，舊帳也不會變。
- 轉帳、代墊、還款、調整不選分類。
