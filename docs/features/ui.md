# 介面

以手機為主的版面：錢包頁、記一筆的入口與畫面、帳號選單。

- **以手機為主**，畫面以行動裝置設計，桌機版只要能用。
- 以 PWA 安裝到主畫面（manifest 已經有了）。
- **不做即時同步**：別人記的帳不會自動出現在畫面上。
- 要支援**下拉重新整理**。iOS 加到主畫面的 PWA 沒有瀏覽器內建的下拉重新整理，要自己實作。

## 錢包頁的版面

手機的錢包頁由上而下是：摘要、帳目列表。標題列左邊是返回的圓鈕，標題置中，右邊是「⋯」。
桌機維持原本的版面。

- **摘要**：數字放大置中。一般錢包顯示餘額，旅遊錢包顯示**我的淨額**（應收或應付）。
  超級管理者打開沒加入的錢包時沒有淨額。
  使用者區的「記一筆」在底部導覽（見[記一筆的入口](#記一筆的入口)）；後台沒有那顆「＋」，
  「記一筆」放在摘要下方，不能記帳時不顯示。
- **⋯**：從底部滑出面板，**不帶標題**，只依序列出這個錢包的所有操作，沒有權限或不適用的不顯示。
  其他頁標題列右邊的 ⋯ 也一樣，點遮罩關閉：

  | 一般錢包 | 旅遊錢包 |
  |---|---|
  | 調整餘額 | 開始結算／取消結算（管理者） |
  | 代墊未還（都還清時不顯示） | 每人淨額 |
  | 成員 | 成員 |
  | 分類 | 異動紀錄 |
  | 異動紀錄 | 詳細設定 |
  | 詳細設定 | 加入／取消最愛 |
  | 加入／取消最愛 | |

- 代墊未還與每人淨額打開成對話框，內容跟桌機頁面上的清單一樣。
- 旅遊錢包**結算中與已結帳時**，清償方案照樣顯示在帳目上方：那時候要做的就是照方案轉帳、確認收款。

**為什麼全部收進 ⋯**：摘要下方原本有一排常用操作，最後一格是「更多」，畫面上的按鈕一多，
帳目被往下擠；而且「更多」跟底部導覽的項目長得像，容易混淆。收進標題列右邊之後，摘要下面就是帳目，
所有操作也只有一個入口。

**為什麼記一筆不收進選單**：記帳是最常用的操作，收進選單每次都要多點一下。

**為什麼一般、旅遊合成一項**：分成兩項時手機底部導覽有四格，「＋」不在正中間；
合成一項後是「錢包」「＋」「帳號」三格。兩種一起列出，也不必先猜要找的群組在哪一種底下。

## 記一筆的入口

手機的使用者區，底部導覽依序是「錢包」「＋」「帳號」，「＋」就是記一筆。桌機在錢包頁的標題列。

- **在錢包頁**（一般或旅遊）點「＋」，直接記到這個錢包。
- **在其他頁**點「＋」，先從底部滑出面板選錢包，選好後進到那個錢包並直接開啟記一筆。
  面板依自己的錢包群組分組，群組照自己排的順序，群組裡跟列表一樣（最愛在前）。
  不顯示的錢包不列，沒有錢包可以選的群組也不列。已結帳的旅遊錢包不列；
  結算中的列出但不能選，旁邊寫「結算中，不能記帳」。
- **不能記帳時**（結算中、已結帳，或帳目沒有載入），「＋」變灰但照樣可以點，點了用通知說明原因。
- 後台的底部導覽沒有「＋」：後台是管理用的，超級管理者要記帳時從錢包頁摘要列的「記一筆」。

**為什麼放在底部導覽正中間**：手機單手操作時，底部中間是拇指最容易點到的位置，
而且不論在哪一頁都在同一個地方，不必先找到錢包頁的按鈕。

**為什麼不能記帳時變灰而不是隱藏**：隱藏會讓底部導覽的位置跳動；變灰再說明原因，使用者才知道是錢包的狀態，
不是按鈕壞了。

## 記一筆的畫面

手機上記一筆（含修改）佔滿整個畫面；桌機照常是對話框。一般錢包與旅遊錢包都一樣。

- 標題列左邊是關閉，標題置中，下面一行是**錢包名稱**：從別頁按「＋」選了錢包進來時，再確認一次記在哪裡。
- **金額**用大字，點了跳出只有數字的鍵盤（金額一律是整數，見[金額](amounts.md)）。
- 選項少的攤開成膠囊，點一下就選好，不用打開下拉選單：
  - 一般錢包：**類型**（支出、收入、代墊、轉出、轉入）是一列分段切換，**分類**是可以換行的膠囊。
  - 旅遊錢包：**付款人**是膠囊，**分攤方式**（均分、指定金額）是分段切換。
  - 轉帳的對方錢包、代墊的對象維持原本的欄位：前者可能很多，後者要能打新的名字。
- 「儲存」是貼在畫面底部的一整條，取消就是左上角的關閉。

**為什麼佔滿整個畫面**：記帳要輸入金額，鍵盤一跳出來，從底部滑出的面板只剩一小塊，
欄位要捲來捲去；整個畫面都給這張表單，類型、金額、分類一眼都看得到。

## 帳號選單

手機底部導覽的最後一格是「帳號」，從底部滑出面板，標題是使用者名稱；桌機在側欄底部的頭像，項目相同。
使用者區與後台是同一份，依序是：

| 項目 | 說明 |
|---|---|
| 管理後台／使用者畫面 | 只有超級管理者有。在使用者區顯示「管理後台」，在後台顯示「使用者畫面」 |
| 錢包設定 | `/wallets/settings`：自己的錢包群組與每個錢包的顯示（見[錢包群組](wallets.md#錢包群組)） |
| 用戶設定 | `/settings/user`：個人資料、改密碼 |
| 系統設定 | `/settings/system`：語系、系統版本 |
| 登出 | |

- 舊的 `/settings` 導向用戶設定，已經加到主畫面或存成書籤的人不會打開變成找不到頁面。

**為什麼分成用戶設定與系統設定**：個人資料與密碼跟著帳號走，換一台裝置登入照樣是同一份；
語系存在這台裝置的 cookie，版本是系統資訊，兩種放在一起時不容易看出改的是哪一種。
