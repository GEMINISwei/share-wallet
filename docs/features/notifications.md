# 通知

哪些事件推播給誰。

以推播通知，原則是只推「要你做點什麼」或「與你直接相關」的事。**一般記帳不推播**。

| 事件 | 通知對象 |
|---|---|
| 旅遊錢包開始結算 | 所有成員，內容是自己要付給誰、或誰會付給自己 |
| 旅遊錢包取消結算 | 所有成員 |
| 付款人標記「我已付款」 | 收款人 |
| 收款被確認 | 付款人 |
| 結帳完成、錢包封存 | 所有成員 |
| 自己記的帳被別人修改或刪除 | 原記帳人 |
| 有人透過邀請連結加入 | 該錢包的管理者 |
| 被升為管理者、被移出錢包 | 當事人 |

iPhone 必須把網站加到主畫面才收得到推播，這是 iOS 的限制。
