# 金額

兩種錢包共用的金額規則：整數、上限、不設幣別。

- 金額**一律是整數**，兩種錢包都一樣。
- 金額**大於 0**；只有調整餘額記下的差額可以是負的。
- 金額與餘額的上限是 2⁵³ − 1（瀏覽器能精確表示的最大整數），記帳會讓餘額超過時擋下。
- **不設幣別**。錢包需要標示是哪一種錢時寫在名稱裡，例如「日本旅遊（日圓）」。
- 群組顯示**群組裡顯示中的錢包餘額的總和**。旅遊錢包沒有餘額，也不分群組。

**為什麼用整數**：日常記帳與分帳都以整數金額進行，用整數可以避免小數的進位誤差，
分攤時也只需要處理整數的零頭。

**為什麼不設幣別**：系統不做換匯，幣別只會是一個標籤。一旦有了這個標籤，就得回答
同幣別才能轉帳嗎、改了幣別既有的轉帳怎麼辦、不同幣別的總和怎麼顯示，而這些規則都沒有實際需求。
用到多種貨幣的使用者自己知道哪些錢包是同一種錢，寫在名稱裡就夠了。
