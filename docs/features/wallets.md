# 錢包與群組

兩種錢包的差別、錢包列表怎麼排、每個人自己的錢包群組，以及刪除錢包。

## 兩種錢包

| | 一般錢包 | 旅遊錢包 |
|---|---|---|
| 本質 | 一份**資產**，有餘額 | **分帳**，算誰欠誰 |
| 用途 | 家用、個人帳戶、共同存款 | 一趟旅程 |
| 交易 | 收入、支出、轉帳、代墊、還款、調整餘額 | 誰付了多少、哪些人分攤 |
| 生命週期 | 持續使用 | 進行中 → 結算中 → 已結帳（封存） |

**兩種錢包之間只有一個交會點**：新增旅遊帳時，付款人可以順便在自己的一般錢包記一筆支出
（見[同步到一般錢包](travel-wallet.md#同步到一般錢包)）。除此之外不互通：不能互相轉帳，
建好的兩筆也不連動，旅遊錢包的結帳只是紀錄，協助大家把帳理清楚，不會寫回任何一般錢包。

## 錢包列表

錢包依[錢包群組](#錢包群組)分開列出，每個群組一頁（`/wallets/groups/<群組>`）。

- 導覽裡只有一項「錢包」。點了之後分「一般錢包」「旅遊錢包」兩段列出群組：
  - 手機從底部滑出面板，選了群組才進去。
  - 桌機在側欄展開，點群組進去；在群組頁或錢包頁時預設展開，再點一次收合。
- 每一段只列出裡面有顯示中錢包的群組，自訂群組與預設群組都一樣。順序是自己在錢包設定排的順序。
  一個都沒有時，不列那一段；兩段都沒有（例如剛註冊、還沒有錢包）時不展開，點「錢包」直接進 `/wallets`，
  在那裡建立錢包時選類型。
- 一般群組的頁面最上方顯示這個群組的總額（見[錢包群組](#錢包群組)），用大字放在一張整塊彩色的卡片裡；旅遊群組不顯示。
- 群組頁只列**顯示中**的錢包。每個錢包是一張卡片，名稱左邊用圖示標出類型：一般錢包是錢包，旅遊錢包是飛機。
- 登入後、打開 `/wallets` 時，進到排在第一個、而且有顯示中錢包的一般群組；一般群組都沒有就換旅遊群組；
  兩種都沒有，進到「一般錢包（未選擇）」。從錢包頁返回時，回到這個錢包所在的群組。
- 每個人可以把錢包設為**最愛**，在錢包頁的選單裡設定、取消；列表上的最愛只顯示星號，不能從列表切換。
- 最愛是**自己的標記**，記在自己的成員紀錄上，別的成員看不到也不受影響。
  只有成員能設最愛：超級管理者打開沒加入的錢包時沒有這個選項。已結帳的錢包也能設。
- 每個群組裡最愛的排在前面，其餘維持加入的先後；**已結帳的一律排在最後**，最愛也一樣。

**為什麼依群組分頁**：兩種錢包要看的數字不一樣（餘額與淨額），旅遊錢包又會隨著一趟趟旅程越積越多；
同一種類型裡，不同幣別或用途的錢包加在一起的總額也沒有意義。讓每個人自己分組，每一頁只看一組。

**為什麼已結帳的最愛也排最後**：已結帳的錢包只能查看，排在進行中的錢包前面只會擋路；
星號留著，要回頭看時還是找得到。

## 錢包群組

每個人可以把自己加入的錢包分組，例如把台幣與日圓的錢包分開，各自看總額。

- 群組是**自己的**：群組本身、錢包放在哪一組、要不要顯示，都記在自己的資料與成員紀錄上，
  別的成員看不到也不受影響。超級管理者打開沒加入的錢包時沒有這些設定。
- 群組分成**一般群組**與**旅遊群組**，建立後不能改。一般錢包只能放進一般群組，旅遊錢包只能放進旅遊群組。
- 每個人各有一個**預設群組**：「一般錢包（未選擇）」與「旅遊錢包（未選擇）」。預設群組不能改名、不能刪除，
  名稱跟著語系顯示。第一次用到群組時（列出群組、建立或加入錢包）自動建立。
- 建立錢包或透過邀請加入時，錢包放進同類型的預設群組，並且顯示。離開錢包會刪掉成員紀錄，
  之後再加入就回到預設群組。
- 自訂群組可以新增、改名、刪除。名稱去掉前後空白後最多 50 字，同一種類型裡不能重複（大小寫視為不同）。
  每種類型最多 20 個群組（含預設群組）。
- **刪除群組時，裡面的錢包移回同類型的預設群組**，不會有錢包因此找不到。
- 群組的順序可以上下移動調整，只跟同類型的群組交換位置，預設群組也一樣可以移動。
  新增的群組排在同類型的預設群組前面。
- 錢包可以設為**不顯示**：不出現在列表、記一筆選錢包的面板、轉帳的對方錢包選單與旅遊帳的同步選單，也不計入群組的總額；
  直接打開網址照常可以用。不顯示只是自己畫面上的設定，不是權限，後端照樣接受轉帳到這個錢包。
- 一般群組的總額只加總裡面**顯示中**的錢包；旅遊群組沒有總額。
- 群組與顯示在**錢包設定**（`/wallets/settings`，入口在帳號選單）調整：分成一般群組、旅遊群組兩段，
  每個群組一張卡片，列出裡面所有的錢包（含不顯示與已結帳的）。群組的選單有上移、下移、改名、刪除，
  預設群組只有上移、下移；錢包的選單有「移到其他群組」與「設為不顯示／設為顯示」。
  不顯示的錢包名稱變淡，旁邊標「不顯示」。

**為什麼預設群組不能刪**：錢包一定要屬於某個群組，刪除群組時才有地方可以放；
有了固定的「未選擇」，新加入的錢包也不必先問要放哪裡。

**為什麼轉帳選單也不列不顯示的錢包**：會把錢包藏起來，通常是暫時不用了；還想常用的錢包，
放進另一個群組或留在「未選擇」就好。

## 刪除錢包

- **管理者隨時可以刪除錢包**，不論一般錢包的餘額與代墊未還、旅遊錢包在哪個狀態（含封存）。
- 刪除是**永久的**：成員、分類、帳目與異動紀錄一起刪掉，無法復原。畫面要輸入錢包名稱才能確認。

**為什麼不設條件**：錢包是一群彼此信任的人自己的帳，要不要留由他們決定，系統不替他們判斷
「餘額不是 0 就不能刪」。這類條件只會逼使用者先記一筆調整把餘額歸零再刪，多一步卻沒有保護到什麼；
真正的保護是刪除前的確認。
